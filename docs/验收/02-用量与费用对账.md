## 3. 用量落库与费用对账

### 3.1 等待落库

用量的落库是**轮询**的（默认 1 秒一轮，`app.yml` 的 `usage.pollIntervalMs: 1000`），
**不是**请求结束立刻可见。所以：

```bash
sleep 3
```

- **对**：等 3 秒后能查到
- **错**：立刻查是空 → 正常，等一下再来；一直空 → 见 §3.4

### 3.2 从响应头拿 reqId，精确查这一条

```bash
export REQID="<上一步 X-Request-Id 的值>"

curl -sS "$API/api/usage/$REQID" \
  -H "Cookie: $SESSION" -H "X-Requested-With: dizzyapi"
```

- **对**：200，`{"record":{"reqId":"…","model":"…","costMicros":"123456","inputTokens":…,"outputTokens":…,"cacheReadTokens":…,"cacheWriteTokens":…,"totalTokens":…,"durationMs":…,"ttftMs":321,"clientIp":"…", …}}`
  - `costMicros` 是**十进制字符串**（整数微元，1 元 = 1 000 000 微元），**不是浮点**
  - `ttftMs`：流式请求有值；非流式是 `null`（**不是 0**）
  - `clientIp` 没采到时是 `null`
  - 用户面**不给** `profile` / `accountId` / `attempts`（那是管理面的字段）
- **错**：
  - `404 USAGE_RECORD_NOT_FOUND` → 没落库，或 reqId 抄错了，或**不是你的记录**（见 [04-导出与越权回归.md](04-导出与越权回归.md) §7）
  - `503 API_USAGE_UNAVAILABLE` → usage 插件不在运行

### 3.3 页面费用 == `/api/usage` 的 `costMicros`（**必须逐字相等**）

1. 浏览器打开 `$WEB/console/usage`（概览页）。
2. 找到刚才那条请求，记下它显示的**消费金额**。
3. 再跑一次 §3.2，把 `costMicros` 换算成元（`/ 1000000`）后比对。

- **对**：两者**完全相等**（费用在**读取时**按当前价格表算，所以改过价格会一起变——这是设计，不是 bug）
- **错**：不一致 → 说明页面与 API 走了两套口径（回归）

再看明细页 `$WEB/console/usage/detail`：同一行、同一金额。

### 3.4 明细列表与汇总

```bash
curl -sS "$API/api/usage?range=30d" \
  -H "Cookie: $SESSION" -H "X-Requested-With: dizzyapi"
```

- **对**：200，里有 `totals`（汇总）、`daily`（按天）、`models`（按模型）、
  `records.items`（明细）+ `records.nextCursor`（keyset 分页游标）
- **错**：
  - `400 API_BAD_REQUEST` → `range` 只能取 `7d` / `30d` / `90d`（**没有**「今天/昨天」档，
    那是网页侧的下拉，网页自己算窗口）
  - `records.items` 空 → 落库没成功：看 gatewayd 日志与 `usage` 插件状态（网关日志 + `/admin/observability`）
  - `pricingAvailable: false` → pricing 插件不在运行 → **费用一律 0**（页面要提示这件事）

> ⚠️ **普通用户的查询强制带会话 `userId`**：不带就是**全站口径**（管理面语义）。
> 网页侧已经把它做成必填位（`queryOf(filters, userId)`），漏传会编译失败——
> 2026-10-30 修掉过一个真越权（任意登录用户能看到全站用量）。

### 3.5 费用按模型分组也对得上

```bash
curl -sS "$API/api/usage?range=30d" \
  -H "Cookie: $SESSION" -H "X-Requested-With: dizzyapi" | grep -o '"costMicros":"[0-9]*"'
```

- **对**：`models` 里每个模型的 `costMicros` 相加 ≈ `totals.costMicros`
  （**≈ 而不是 =** 是因为 `totals` 与 `models` 的分组口径可能含未分组项；
  差得多就是回归）

**出处**：`packages/api/src/routes/usage.ts`（`usage` / `usageDetail`）、
`packages/api/src/views/usage.ts`（`usageRowOf` / `usageDetailOf`）、
`packages/usage/src/service.ts`（费用在读取时按 pricing 算）。

## 附录 B：本文档未覆盖但值得抽查的

- `/console/models`（模型广场）：价格、可用性、覆盖账号数是否与 `pricing` 一致
- `/console/top-up`（充值）：下单 → `pending` → 管理员「确认到账」→ 余额真的加了
- `/console/redeem`（兑换）：兑换一次只加一次钱（并发也不能加两次）
- `/admin/billing`（结算）：同一 `reqId` 只扣一次；`review` 状态的记录要人工核查
- `/admin/observability`（运维总览）：任一数据源缺席只降级那一块，**不整页 503**
- `/console/api-docs` 与 `/llms.txt`：入口表与错误码表由代码实时派生，**不许**手写
- `/admin/usage`（全站用量）：隔离区（`usage_rejected`）里的记录要能「忽略 / 重放」

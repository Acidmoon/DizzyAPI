# 验收 · 错误码速查

---

## 附录 A：一页速查（错误码 → 状态码）

| 稳定码 | 状态 | 出处 | 含义 |
|---|---|---|---|
| `INVALID_API_KEY` | 401 | `modules/keyauth` | key 不对（**含**「曾有效但已过期」时用 `API_KEY_EXPIRED`） |
| `MISSING_API_KEY` | 401 | `modules/keyauth` | 没带 `Authorization: Bearer` |
| `API_KEY_EXPIRED` | 401 | `contracts/keygate.go` | key 已过期（真拦） |
| `API_KEY_SPENDING_LIMIT` | 402 | `contracts/keygate.go` | key 金额上限到了（真拦） |
| `API_KEY_CONCURRENCY_LIMIT` | 429 | `contracts/keygate.go` | key 并发满（真拦） |
| `USER_CONCURRENCY_LIMIT` | 429 | `contracts/keygate.go` | 用户并发满（真拦） |
| `INSUFFICIENT_BALANCE` | 402 | `contracts/quota.go` | 余额 ≤ 阈值（pre 相位，不转发上游） |
| `QUOTA_SNAPSHOT_UNAVAILABLE` | 503 | `contracts/quota.go` | 严格模式下余额快照不可用 |
| `MODEL_NOT_PRICED` | 403 | `contracts/keygate.go` | 模型没配价（闸门开着时真拒） |
| `PRICING_SNAPSHOT_UNAVAILABLE` | 503 | `contracts/keygate.go` | 定价闸门开着但快照不可用（fail-closed） |
| `CONTENT_BLOCKED` | 403 | `contracts/contentaudit.go` | 命中 block 规则（不转发上游） |
| `CONTENT_AUDIT_SNAPSHOT_UNAVAILABLE` | 503 | `contracts/contentaudit.go` | 严格模式下审核快照不可用 |
| `ALL_ACCOUNTS_SATURATED` | 503 | `contracts/contracts.go` | 所有候选账号都在冷却 / 被占满 |
| `MODEL_NOT_SERVED` | 404 | 路由层 | 没有账号声明这个模型 |
| `INVALID_REQUEST` | 400 | `internal/httpapi` | body 不是合法 JSON / 缺 model |
| `METHOD_NOT_ALLOWED` | 405 | `internal/httpapi` | 方法不对 |
| `API_UNAUTHORIZED` | 401 | `packages/api/src/errors.ts` | 未登录 / 会话失效 |
| `API_FORBIDDEN` | 403 | 同上 | 非管理员 |
| `API_REQUEST_HEADER_REQUIRED` | 403 | 同上 | 少 `X-Requested-With: dizzyapi` |
| `API_HOST_FORBIDDEN` | 403 | 同上 | Host 头不对（直连时） |
| `API_ORIGIN_FORBIDDEN` | 403 | 同上 | Origin 不同源 / `Sec-Fetch-Site: cross-site` |
| `API_NOT_FOUND` | 404 | 同上 | 没有这个接口 |
| `USAGE_RECORD_NOT_FOUND` | 404 | `packages/api/src/routes/usage.ts` | 没有这条记录（**含**「不是你的」） |
| `API_USAGE_UNAVAILABLE` | 503 | 同上 | usage 插件不在运行 |
| `API_KEY_UNAVAILABLE` | 503 | `packages/api/src/errors.ts` | api-key 插件不在运行 |
| `AUDIT_UNAVAILABLE` | 503 | 同上 | 审计插件不在运行（写操作照常成功） |
| `CONTENT_AUDIT_UNAVAILABLE` | 503 | 同上 | 内容审核插件不在运行（不拦人） |
| `PRICING_PRICE_INVALID` | 400 | `packages/api/src/routes/pricing.ts` | 价格字段不是字符串/数字 |
| `PRICING_NOT_FOUND` | 404 | 同上 | 没有这个模型的价格 |

**兜底规则**（`packages/api/src/errors.ts` 的 `statusOfCode`，没在表里的码按后缀判）：
`*_INVALID` / `*_REQUIRED` / `*_UNSUPPORTED` → 400；`*_NOT_FOUND` → 404；
`*_FORBIDDEN` → 403；`*_TAKEN` / `*_CONFLICT` / `*_EXISTS` / `*_LIMIT_REACHED` → 409；
`*_RATE_LIMITED` / `*_ATTEMPTS_EXCEEDED` → 429；`*_UNAVAILABLE` / `*_NOT_READY` → 503；
`*_TOO_LARGE` → 413；**其余一律 500**（未知内部错误不伪装成 400）。

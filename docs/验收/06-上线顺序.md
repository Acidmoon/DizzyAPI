## 10. 上线顺序（**顺序反了就是全站 401**）

> ⚠️⚠️ **这是整份清单里唯一一条「做错一次就全站不可用」的步骤。**

### 10.1 为什么

`keys.replace` 走 `decodeParams` + `DisallowUnknownFields`：

- TS 现在推的 key 快照带 `expiresAt` / `spendingLimitMicros` / `concurrencyLimit`，
  而 Go 侧 `SnapshotVersion` 仍是 **1**（没 bump）。
- **旧 Go 二进制**先过版本检查（1 == 1 通过），再因**未知字段**把**整份快照拒掉**
  → key 快照缓存清空 → **所有 API key 校验失败 → 全站 401**。
- `accounts.replace` 同理：整份账号快照被拒 → 账号缓存清空 → **全部 503**。

### 10.2 必须按这个顺序

```bash
# ── ① 先在本地交叉编译新的 Go 二进制（服务器上没有 Go 工具链）
GOOS=linux GOARCH=amd64 go build -trimpath -o bin/gatewayd ./cmd/gatewayd

# ── ② 先换服务器上的 bin/gatewayd（旧的还在跑没关系）
scp bin/gatewayd root@<SERVER_IP>:/opt/dizzyapi/bin/gatewayd.new
ssh root@<SERVER_IP> 'cd /opt/dizzyapi && mv bin/gatewayd.new bin/gatewayd && chmod +x bin/gatewayd'

# ── ③ 再换 TS 侧代码（app.yml / data/ 不要覆盖）
git archive --format=tar HEAD | ssh root@<SERVER_IP> 'cd /opt/dizzyapi && tar xf -'

# ── ④ 最后重启（systemd 会用新二进制拉起 gatewayd）
ssh root@<SERVER_IP> 'systemctl restart dizzyapi'

# ── ⑤ 验活
ssh root@<SERVER_IP> 'systemctl is-active dizzyapi'
curl -sS "$BASE/healthz"
```

- **对**：`active` + `/healthz` 200 + [00-准备.md](00-准备.md) §0.3 的两条都通
- **错**：
  - `inactive` → `journalctl -u dizzyapi -n 100` 看日志
  - `/healthz` 通但**任何 `/v1/*` 都 401** → **顺序反了**：旧二进制 + 新 TS。
    修法：把 ② 重做一遍（换上新二进制）再重启。**不要**回滚 TS，先换二进制。

### 10.3 部署纪律

- 服务器上 `pnpm` 走网络会卡住 → 依赖统一用
  `npx -y pnpm@11.21.0 install --frozen-lockfile --offline` 复用已装好的 store。
- **不要覆盖**服务器的 `app.yml`、`data/`、`bin/`（`bin/gatewayd` 按上面单独换）。
- 服务器 `app.yml` 的 `account-priority.httpListen` 必须是 `18080`
  （仓库默认的 `8080` 在 <生产服务器> 属于 sub2api）。
- 反向代理（宝塔 nginx）必须把 `Host` 改写成回环：
  `/api/*` → `127.0.0.1:7791`，其余 → `127.0.0.1:7792`；`/` 还要把 `Origin` 改写成
  `https://127.0.0.1:7792`。**不改就是 403**（防 DNS rebinding）。
- 部署前备份 `/opt/dizzyapi/data/` 与代码。
- 部署后检查：`systemctl is-active dizzyapi` + `/healthz` +
  [01-账号与模型请求.md](01-账号与模型请求.md) §1.3 的 key 能用 + 同册 §2 的一条真请求成功。

### 10.4 上线后 24 小时要盯的

| 现象 | 多半是 | 去哪看 |
|---|---|---|
| 全站 401 | 顺序反了（旧二进制） | §10.2 的修法 |
| 全站 503 | 账号快照被拒 / 没有可用账号 | gatewayd 日志 + `accounts.status.runtime` |
| 余额已负还在 200 | 余额快照心跳断了 | `quota.status`（`failureStreak` / `ageMs`） |
| 用量明细是空的 | `usage` 轮询没推进游标 | `usage.status` / `usage.stats`（`gap` / `dropped`） |
| 价格算成 0 | `pricing` 插件不在运行 | 页面会提示 `pricingAvailable: false` |
| 页面样式是旧的 | 静态资源缺 `?v=<hash>` | `/assets/app.css?v=…` 的哈希要对上正文 |

**出处**：`AGENTS.md` §7「Go · 部署顺序」与 §6.3「部署」；
`internal/bridge` 的 `decodeParams` + `DisallowUnknownFields`。
